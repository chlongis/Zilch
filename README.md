# Zilch
Freelance work app designed to be consumer friendly with a focus on rideshare/food delivery. ZERO FEES FOR DRIVER AND DINER.


Zilch is a peer-to-peer based freelance app that does not take a cent out of your pocket. Sign up as a driver, get verified, and start earning ALL OF YOUR MONEY today!

Zilch is currently a Work in Progress and is looking for people in the Minnesota West Metro area to drive. See website to pledge to be a driver.
